# 词间 · 本地四级阅读练习室

双击项目外层的 `启动词间.cmd`，然后打开 http://127.0.0.1:8765 。首次交付已经安装依赖并构建。运行只需要 Python。

## 使用

1. 在「API 设置」填写 Base URL、模型名和 API Key。默认地址为 DeepSeek；可改为 HTTPS 的 Chat Completions 兼容接口。地址不要带 `/chat/completions`，模型名以你的服务商为准。保存设置不调用 API。
2. 设置每轮词数（1–90）、旧词比例与原始编号范围，点击重新选词。也可在「词库与状态」手动勾选。首轮无旧词时用新词补足；可用词不足时显示实际数量。
3. 点击生成新一轮，每约 10 个词独立生成一篇 150–200 词短文。每轮目标顺序随机重排；同批再练保留该轮词集并保证输入顺序不同。生成提示提供历史标题和开头，要求更换人物、情节与场景；自动检查完全重复，故事新颖程度仍需阅读判断。
4. 阅读高亮词和篇末中文释义，全文抄写后勾选完成。「同批再练」重复当前词集；右侧「生成新一轮」使用当前已选词，需点击「按比例重新选词」更新新旧混合方案。
5. 漏词可补写。失败或网络超时不自动重试，点击继续可能产生新的 API 用量。已返回的内容永远保留；篇幅或重复问题可同批再练。

## 本地数据

- `data/vocabulary.json`：词库原始编号、词形、释义、扫描文本及待核对标记。
- `data/state.json`：学习状态与全部轮次的主档案；原子写入。
- `data/rounds/<id>.json`：每轮词表快照、请求顺序、完整提示词、API 返回、文章及检查结果。
- `data/rounds/<id>.md`：每轮可直接阅读的短文与词义注释。
- `data/config.local.json`：本机 API 设置，含明文 Key；不放入前端、导出或 Git。备份学习资料时保留前三项即可。网页「导出学习档案」提供不含配置文件的 JSON 备份。

词表共保留 5,640 个编号位置。首次提取时 3,577 条文本较完整、2,063 条待核对（含缺失位置、残缺释义和段落识别候选）。这不是对扫描文本的人工校对；待核对条目默认不进入生成，可在界面中对照原文补全。重复表格已按编号合并。

统计区分提交次数、正文出现次数、覆盖轮数；标题和词义注释不计数。使用完整词形匹配及词表明确的拼写变体，不把 accepted 自动算为 accept。只有实际在正文出现才成为旧词。「已掌握」须手动设置，不因出现次数自动判定。自动选词跳过已掌握和待核对词，旧词优先待复习、覆盖轮数少、最近接触较早的条目。

## 开发与验证

后端：`python server.py`。前端开发：`npm run dev`（http://127.0.0.1:5173，代理本地服务）。构建：`npm run build`，产物由 Python 服务提供。测试：`python -m unittest discover -s tests`。类型检查：`npx tsc --noEmit`。

仅监听本机回环地址，不部署。模拟 API 测试不产生费用；真实 API 需配置 Key 后验证。

接口参考：https://api-docs.deepseek.com/api/create-chat-completion/


## 朗读与点击查词

文章上方可播放、暂停、停止及调整语速。优先使用浏览器英语语音；内置浏览器未提供英语语音时，Windows 服务使用已安装的英语语音生成 WAV，再通过网页播放器播放。音频缓存在 `data/audio`，不使用生成文章的 API，也不额外购买语音服务。另一台 Windows 电脑需要有英语语音包。

正文中的每个英文单词均可点击。已核对词库中的词直接显示中文；未收录词按点击调用已配置的 API，结果存入 `data/dictionary-cache.json`。不会批量翻译整篇文章，也不会因查词改变单词学习进度。API 返回的是通用释义，需结合上下文理解。

复制到另一台 Windows 电脑时，保留 `dist/client`、`data`、`server.py`、`scripts/speak.ps1`、`start.ps1` 和外层 `启动词间.cmd`；最简单是复制整个项目，但可跳过 `node_modules`。安装 Python 并加入 PATH 后双击启动。API 设置含 Key，只有迁移到自己的电脑时才一并复制；给别人使用应移除 `data/config.local.json`。Git 不包含构建产物、Key、学习记录和缓存，所以仅从 Git 恢复需要先 `npm ci`、`npm run build`，并单独迁移自己的 `data/state.json` 与 `data/rounds`。

浏览器语音接口参考：https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis
